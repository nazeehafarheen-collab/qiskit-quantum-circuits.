# Quantum Computing with Qiskit 

This repository documents my journey in building and experimenting with **quantum circuits** using IBM’s open-source framework, **Qiskit**.

### About Qiskit
Qiskit is a Python-based SDK for quantum computing. It allows me to design circuits, run them on simulators, and even execute them on real IBM Quantum hardware.

### Goals of This Repository
- Implement fundamental quantum circuits (Bell states, superposition, entanglement).
- Explore quantum algorithms like Grover’s search and Quantum Fourier Transform.
- Share beginner-friendly, well-documented code for students and enthusiasts.
- Connect my IT background with cutting-edge quantum computing concepts.

### Structure
- `circuits/` → Basic quantum circuits in Python  
- `algorithms/` → Implementations of quantum algorithms  
- `notes/` → Explanations, references, and learning resources  

### Next Steps
I will continue adding projects as I progress, including experiments on IBM Quantum cloud devices and hybrid quantum-classical workflows.
